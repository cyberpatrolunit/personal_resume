# Slussen Pastel Section Pass Design

## Goal

Refine the redesigned site after review by reducing the scale of the main Wow headline, using Slussen for headings throughout the current site, and adding subtle pastel gradients to major page areas.

## Typography

- Keep body copy in the existing clean system font stack.
- Use Slussen for `h1`, `h2`, and `h3` by default.
- Keep the strongest expanded Slussen treatment for the Wow headline, header mark, and other display moments.
- Reduce the Wow headline size so the intro feels lighter and more efficient.

## Section Color

- Use full-section pastel gradients instead of decorative shapes.
- Keep gradients low contrast so project imagery and text remain the primary focus.
- Give each major domain area a distinct but quiet color temperature:
  - Wow: mint and warm white.
  - Selected work: white to pale blue-green.
  - Archive: pale lavender and blue-gray.
  - Capabilities: pale aqua and green.
  - About: warm white and blush.
  - Contact: light, high-clarity call-to-action band.

## Scope

This is a visual styling pass only. It does not change project content, routing, data shape, or interaction behavior.
